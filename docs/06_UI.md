# UI & UX Documentation - Video Repeat Studio

## 1. Overview & Aesthetic Direction
Video Repeat Studio features a clean, modern desktop application interface built for media editing and video processing workflows on Windows 10 & 11.

- **Theme**: Dark mode by default
- **Palette**:
  - Background App: `#070B14`
  - Sidebar: `#0D1321`
  - Surface Card: `#111827`
  - Surface Raised: `#172033`
  - Border: `#273249`
  - Primary Accent: `#3B82F6` (Hover `#2563EB`)
  - Success: `#22C55E`
  - Warning: `#F59E0B`
  - Danger: `#EF4444`
  - Text Main: `#F8FAFC`
  - Text Secondary: `#94A3B8`
  - Text Muted: `#64748B`

## 2. Terminology & Controls

### Section A — Số lần lặp toàn bộ video
- **When Duration Limit / Target OFF**:
  - `Số lần lặp`: Editable text/number input `[ 10 ]`.
- **When Duration Limit / Target ON**:
  - Input is **disabled and dimmed** (`opacity-50 pointer-events-none`).
  - Label badge: `[ 19x ] Tự động`.
  - Helper text: `Số lần lặp được tự động tính dựa trên thời lượng video gốc và thời lượng xuất mong muốn.`

### Section C — Thời lượng video xuất mong muốn
- **Toggle Label**: `Giới hạn / Mục tiêu thời lượng xuất`
- **Presets**: 30 phút, 1 giờ, 2 giờ, 3 giờ, 6 giờ, 8 giờ, 10 giờ, 12 giờ.
- **Helper text**: `Phần mềm tự tính số lần lặp cần thiết để đạt đúng thời lượng đã chọn và tự cắt phần dư ở vòng cuối.`

### Live Summary Panel
- `Video gốc`: `00:09:50.000`
- `Số lần lặp cần thiết`: `19x (Tự động)`
- `Vòng đầy đủ`: `18`
- `Đoạn vòng cuối`: `00:03:00.000`
- `Fade In âm thanh`: `00:00:05.000` (or `Tắt`)
- `Thời lượng thực tế xuất`: `03:00:00.000`

## 3. Components System (`src/renderer/src/components/`)
- `Sidebar.tsx`: Navigation rail with collapse state.
- `TopHeader.tsx`: Page title and system status badges.
- `DurationLimitControl.tsx`: Reusable Duration Target control component with toggle, `HH:MM:SS.mmm` input, 8 presets, and Vietnamese helper text.
- `JobProgressBar.tsx`: Real-time machine-readable progress bar.
- `VideoPlayer.tsx`: Frame-precise player with Fade In audio preview ramp.
- `StatCard.tsx`, `StatusBadge.tsx`, `EmptyState.tsx`, `Modal.tsx`.
